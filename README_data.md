## Pre-computed Results (INCLUDED)

### bert_training_data.csv

5,533 labeled utterances: 2,833 from 174 Korean counseling sessions
(multi-turn, primary corpus) and 2,700 from the English counseling corpus
(single-turn, auxiliary corpus). Used for supervised classification,
cross-lingual semantic analysis (Wasserstein/ARI/Silhouette), and
language-controlled HDBSCAN clustering.

**Columns:**
- `text`: utterance text (Korean or English)
- `lang`: language code (`ko` / `en`)
- `label`: binary risk label (0=non-risk, 1=risk)
- `level_primary`: L0–L3 risk level index (0=No distress, 1=Mild, 2=Moderate, 3=Severe)
- `L1`, `L2`, `L3`: binary flags per level
- `dialogue_id`: session + chunk identifier

**Label distribution (full corpus, N=5,533):**

| `level_primary` | Level | N | % |
|---|---|---|---|
| 0 | L0 (No distress) | 371 | 6.7% |
| 1 | L3 (Mild) | 2,245 | 40.6% |
| 2 | L2 (Moderate) | 2,766 | 50.0% |
| 3 | L1 (Severe) | 151 | 2.7% |

**Note:** These 2,833 Korean rows represent labeled utterances extracted
from 174 full sessions (mean 286 total turns); they are NOT 2,833 separate
sessions. Of 174 sessions, N=173 meet the quality criterion (≥84 total
turns; 0.6% attrition) for temporal survival analysis. The 2,700 English
rows are drawn from single-turn counseling posts (auxiliary corpus; see
paper Table 1 for full corpus composition).

### detection_coverage.csv

Session-level risk detection coverage as a function of turn budget.
Generated by `06_detection_coverage.py` using klue/RoBERTa L2 classifier.

**Columns:**
- `turn_budget`: number of client turns observed
- `recall`: session-level recall (any-risk-until-t)
- `f1`: session-level F1
- `tp`: true positive count
- `n_sessions`: total sessions (N=154, ≥84 client turns)

**Key values:**

| Turn Budget | Recall | F1 |
|---|---|---|
| 4 | 0.526 | 0.689 |
| **12 (MSW₀.₅)** | **0.857** | **0.923** |
| **32 (MSW₀.₉)** | **0.987** | **0.993** |
| 48 | 1.000 | 1.000 |

### ko_dialogue_stats_endpoint.csv

Session-level statistics from pilot study (N=92).
Note: The paper uses the expanded N=173 dataset (requires AI Hub access).
This file is provided for reference only.

**Columns:**
- `dialog_id`: category/session/checker identifier (e.g.,
  `label_depression_1_check_D011.json`), derived from the AI Hub file
  naming convention (category: depression/anxiety/addiction/normative;
  session number; annotator/checker code). Contains no counseling
  utterance text.
- `total_turns`: total turns in the session
- `has_risk`: binary session-level risk flag
- `first_risk_turn`: turn index of first detected risk cue (if any)

## Data Availability

### Korean raw sessions (ko_raw_all.jsonl) and processed utterances (bert_training_data.csv) — NOT INCLUDED

Due to AI Hub Terms of Use (Korean residents only), raw and processed
Korean counseling transcripts — including individual utterance text —
cannot be redistributed in any form, whether as raw session files or as
derived per-utterance CSVs.

To reproduce results using Korean data:
1. Register at https://www.aihub.or.kr (Korean residents only)
2. Download Dataset No. 71806
   - Total: 1,661 sessions (depression 484, anxiety 487, addiction 448, normative 242)
3. Run preprocessing to regenerate `bert_training_data.csv` locally:
   ```bash
   python 01_bert_training.py --data YOUR_DATA_PATH
   ```

Once regenerated locally, `bert_training_data.csv` will contain 5,533
labeled utterances (2,833 Korean + 2,700 English) with the following
label distribution (full corpus, by `level_primary`):

| `level_primary` | Level | N | % |
|---|---|---|---|
| 0 | L0 (No distress) | 371 | 6.7% |
| 1 | L3 (Mild) | 2,245 | 40.6% |
| 2 | L2 (Moderate) | 2,766 | 50.0% |
| 3 | L1 (Severe) | 151 | 2.7% |

This table is provided for verification purposes only — to confirm your
locally regenerated file matches the corpus used in the paper. It does
not substitute for the file itself.

## Pre-computed Results (INCLUDED)

### detection_coverage.csv

Session-level risk detection coverage as a function of turn budget.
Generated by `06_detection_coverage.py` using klue/RoBERTa L2 classifier.
Contains only aggregate recall/F1 statistics — no utterance text.

**Columns:**
- `turn_budget`: number of client turns observed
- `recall`: session-level recall (any-risk-until-t)
- `f1`: session-level F1
- `tp`: true positive count
- `n_sessions`: total sessions (N=154, ≥84 client turns)

**Key values:**

| Turn Budget | Recall | F1 |
|---|---|---|
| 4 | 0.526 | 0.689 |
| **12 (MSW₀.₅)** | **0.857** | **0.923** |
| **32 (MSW₀.₉)** | **0.987** | **0.993** |
| 48 | 1.000 | 1.000 |

---

### ko_dialogue_stats_endpoint.csv

Session-level statistics from pilot study (N=92).
Note: The paper uses the expanded N=173 dataset (requires AI Hub access).
This file is provided for reference only.

Contains only session-level identifiers and aggregate statistics —
**no counseling utterance text**.

**Columns:**
- `dialog_id`: category/session/checker identifier (e.g.,
  `label_depression_1_check_D011.json`), derived from the AI Hub file
  naming convention (category: depression/anxiety/addiction/normative;
  session number; annotator/checker code).
- `total_turns`: total turns in the session
- `has_risk`: binary session-level risk flag
- `first_risk_turn`: turn index of first detected risk cue (if any)

### keyword_lexicon.csv

Risk-cue keyword lexicon used for the density proxy computation.
Korean clinical risk expressions curated by a licensed clinical
psychologist. Contains isolated keywords only — no counseling
utterance text or session-derived content.
